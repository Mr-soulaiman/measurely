# Buildoser Project Guidelines

## Canonical Domain & SEO
- The canonical domain for Buildoser is `https://www.buildoser.com`.
- All `<loc>` URLs in `public/sitemap.xml` must use `https://www.buildoser.com/...`.
- `public/robots.txt` points to `Sitemap: https://www.buildoser.com/sitemap.xml`.
- Canonical tags, Open Graph tags, and JSON-LD structured data must always reference `https://www.buildoser.com/...`.
- Static files (`sitemap.xml`, `robots.txt`, `ads.txt`) are served directly at the root.
